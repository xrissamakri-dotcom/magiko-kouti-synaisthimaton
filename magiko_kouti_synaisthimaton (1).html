Το μαγικό κουτί των συναισθημάτων

Ανακαλύπτουμε τα συναισθήματά μας, ακούμε τις ιστορίες και μαθαίνουμε τι μπορεί να μας βοηθήσει.

1. Άνοιξε τις κάρτες των συναισθημάτων

Πάτησε μια κάρτα για να μάθεις περισσότερα. Όλα τα συναισθήματα είναι αποδεκτά!

Διάλεξε μια κάρτα για να εμφανιστεί η περιγραφή της.

2. Μικρές ιστορίες

🎨 Η ζωγραφιά της Μαρίας

Η Μαρία τελείωσε μια ζωγραφιά και θέλει να τη δείξει στην τάξη. Χαμογελά και ανυπομονεί.

Πώς μπορεί να νιώθει; Χαρά — μπορεί να νιώθει περήφανη για τη δουλειά της.

🧸 Το παιχνίδι του Νίκου

Ο Νίκος ήθελε να παίξει με ένα παιχνίδι, αλλά τώρα το χρησιμοποιεί ένα άλλο παιδί. Ο Νίκος στενοχωρήθηκε.

Τι μπορεί να κάνει; Να πει πώς νιώθει, να ζητήσει να παίξουν μαζί ή να περιμένει τη σειρά του με βοήθεια.

🌩️ Ο δυνατός ήχος

Η Ελένη ακούει έναν ξαφνικό δυνατό ήχο και τρομάζει.

Τι μπορεί να τη βοηθήσει; Να πάει κοντά σε έναν ενήλικα που εμπιστεύεται και να του πει ότι φοβήθηκε.

3. Ώρα για παιχνίδι ερωτήσεων!

Ερώτηση 1 από 5

Πώς μπορεί να νιώθει ένα παιδί όταν παίζει με τους φίλους του και περνά όμορφα;

🎉 Μπράβο που προσπάθησες!

Κάθε συναίσθημα έχει τη θέση του. Μπορούμε να μιλάμε για όσα νιώθουμε και να ζητάμε βοήθεια.

4. Τι μπορώ να κάνω όταν το συναίσθημα είναι πολύ δυνατό;

  • 🌬️ Παίρνω αργές, ήρεμες αναπνοές.
  • 🗣️ Λέω με λόγια τι νιώθω.
  • 🧸 Κάνω ένα μικρό διάλειμμα σε ασφαλές μέρος.
  • 🤝 Ζητώ βοήθεια από έναν ενήλικα που εμπιστεύομαι.
  • 💗 Θυμάμαι ότι δεν χρειάζεται να νιώθουμε όλοι το ίδιο.

Δεν υπάρχουν «κακά» συναισθήματα. Μπορούμε να μάθουμε ασφαλείς τρόπους να τα εκφράζουμε.

Δραστηριότητα για παιδιά 4–6 ετών • Μπορεί να γίνει μαζί με/με την καθοδήγηση του/της εκπαιδευτικού.
